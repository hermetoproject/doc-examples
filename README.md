# README

A simple Python project with a single Python-only dependency that outputs
colored text to the terminal. Demonstrates using Hermeto to fetch
dependencies and enable a hermetic container build for `pip`.

For a full walkthrough of how this example works, see the
[pip example section](https://github.com/hermetoproject/hermeto/blob/main/docs/pip.md#example)
in the Hermeto docs.
